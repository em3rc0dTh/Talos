# TALOS — Deprecated Artifacts

This directory retains superseded Talos documentation and design artifacts when a newer version replaces them.

## Rule

Do not delete architectural history merely because a contract evolves.

When an artifact is superseded:

1. create the new version in the appropriate active lifecycle directory;
2. update references/status;
3. move or copy the superseded artifact here when appropriate;
4. record why it was deprecated and which artifact replaced it.

The purpose is to preserve decision history and prevent old assumptions from silently returning later.

Deprecated does not mean useless. It means **not authoritative for the current system**.
